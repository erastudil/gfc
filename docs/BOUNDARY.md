# boundary

this gift is the writing standard for human-facing agent prose. complete for that job.

## ships

| | |
|---|---|
| standard | intuition first, name second. the is, once. contained analogy. match the ask. silence over hedge. fresh wording |
| modes | prose · educate |
| hygiene | machine-checkable tells. linter owns the list |
| echo | exact n-grams across a corpus of prior answers |
| writer | `gfc strip` mechanical pass toward the is |
| prompts | drop-in genome and canon. warehouse is per project |
| skill | when to check, how to fix, when to stop |
| tools | lint · echo · strip · prompt emit · check |
| license | AGPL-3.0-or-later. covenant in `COVENANT.md` |

`docs/SPEC.md` is the law. tools fail closed against it.

## completeness

an implementer who has only this repository can wire the standard into an agent desk, a CI job, or a skill slot. named sources in SPEC are files in this tree. no private path is load-bearing.

word lists as the verdict are off this gift. structure is the cheap gate. a frontier-model judge is Platitude's job.
